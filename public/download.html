🎬 AI Drama Studio

Aplikasi web untuk membuat cerita drama AI dengan prompt video yang berkesinambungan

📥 Cara Download Proyek

Metode 1: Download Source Code (Recommended)

Proyek ini sudah di-build dan siap digunakan. Untuk mendapatkan file ZIP:

  1. Buka terminal/command prompt di folder proyek
  2. Jalankan perintah berikut:
zip -r ai-drama-studio.zip . -x "node_modules/*" -x "dist/*" -x ".git/*"

Atau gunakan file manager untuk compress folder proyek.

Metode 2: Download Build Output

Untuk mendapatkan versi production yang sudah di-build:

  1. Folder dist/ berisi file yang sudah di-build
  2. Compress folder dist/ menjadi ZIP
  3. File dist/index.html bisa langsung dibuka di browser

Metode 3: Clone & Build Sendiri

git clone [repository-url]
cd ai-drama-studio
npm install
npm run build

📁 Struktur File Penting

  • src/App.tsx - Komponen utama aplikasi
  • src/types.ts - TypeScript type definitions
  • src/services/characterAnalyzer.ts - Analisis karakter otomatis
  • src/services/storyGenerator.ts - Generator cerita & prompt video
  • src/services/validator.ts - Validasi konsistensi scene
  • src/services/storage.ts - Penyimpanan & ekspor data
  • dist/ - Build output (production)
  • package.json - Dependencies & scripts

🚀 Cara Menjalankan

Development Mode:

npm install
npm run dev

Buka http://localhost:3000

Production Build:

npm install
npm run build

File hasil build ada di folder dist/

ℹ️ Informasi:
  • Aplikasi berjalan dalam Mode Demo menggunakan template cerita
  • Tidak memerlukan API key untuk menggunakan
  • Setiap scene berdurasi tepat 10 detik
  • Prompt video dalam Bahasa Inggris, UI dalam Bahasa Indonesia
  • Character Lock menjaga konsistensi visual di semua scene
⚠️ Catatan:

Aplikasi ini menggunakan template cerita untuk mode demo. Untuk integrasi AI generatif sungguhan, diperlukan backend server dengan API key dari provider AI (OpenAI, Anthropic, dll).

✨ Fitur Utama

  • ✅ Input karakter fleksibel dengan deskripsi bebas
  • ✅ Analisis karakter otomatis (ciri user vs AI)
  • ✅ Character Lock untuk konsistensi visual
  • ✅ Satu prompt video final utuh per scene
  • ✅ Durasi tepat 10 detik per scene
  • ✅ Dialog dengan timecode dan emosi
  • ✅ Kesinambungan cerita antar scene
  • ✅ Ekspor TXT & JSON
  • ✅ Validasi konsistensi otomatis
  • ✅ Regenerate scene individual
