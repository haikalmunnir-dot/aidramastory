================================================================================
                    AI DRAMA STUDIO - CARA MENDAPATKAN ZIP
================================================================================

PROYEK SUDAH SIAP! Berikut cara mendapatkan file ZIP:

================================================================================
CARA 1: ZIP GENERATOR OTOMATIS (PALING MUDAH)
================================================================================

1. Jalankan aplikasi:
   npm run dev

2. Buka browser ke:
   http://localhost:3000/zip-generator.html

3. Klik tombol "📦 Download ZIP"

4. File ZIP akan otomatis terdownload!

================================================================================
CARA 2: COMMAND LINE (Terminal/Command Prompt)
================================================================================

Windows (PowerShell):
   Compress-Archive -Path .\* -DestinationPath ai-drama-studio.zip

Windows (CMD dengan Git):
   zip -r ai-drama-studio.zip . -x "node_modules/*" -x "dist/*"

Mac/Linux:
   zip -r ai-drama-studio.zip . -x "node_modules/*" -x "dist/*" -x ".git/*"

================================================================================
CARA 3: FILE MANAGER (Tanpa Command Line)
================================================================================

Windows:
   1. Buka folder proyek
   2. Ctrl+A (pilih semua)
   3. Klik kanan → Send to → Compressed (zipped) folder
   4. Rename menjadi ai-drama-studio.zip

Mac:
   1. Buka folder proyek
   2. Klik kanan → Compress
   3. Rename menjadi ai-drama-studio.zip

================================================================================
CARA 4: MENJALANKAN APLIKASI
================================================================================

Setelah mendapatkan ZIP atau langsung dari folder:

1. Install dependencies:
   npm install

2. Jalankan development server:
   npm run dev

3. Buka browser:
   http://localhost:3000

4. Untuk production build:
   npm run build
   
   File hasil build ada di folder dist/
